# MyTime — 统计与时间线视觉优化设计

## 概述

优化统计页面与时间线页面的视觉质量，新增周视图，重做趋势图为可筛选的堆积柱状图。

## 1. 时间线 — 新增周视图

### 1.1 日/周切换

顶部日期导航栏下方增加一行 Tab 切换：`日` / `周`。

- 日视图：保留现有实现（0–24h 纵向时间轴，双指缩放）
- 周视图：7 天堆积柱状图

### 1.2 周视图布局

- 7 根柱子并排，对应周一到周日
- 每根柱子按分类堆叠，颜色对应分类色
- 纵轴为时长（小时），横轴标星期几
- 底部显示每天总时长
- 点击某天柱子可跳转到该天的日视图

### 1.3 数据

周视图数据在当前周范围内计算，取每天每分类的时长总和。使用 `StatsMetrics._trend` 类似逻辑，但按分类细分。

## 2. 统计 — 堆积柱状图（趋势图）

### 2.1 交互

- 柱状图上方增加一个筛选按钮，文案显示当前已选分类数，如 `已选 3 个分类`
- 点击弹出 Bottom Sheet，列出所有分类，每行：`[勾选框] 分类名 分类色块`
- 用户按**点击顺序**选择：第一次点击的分类在最底层，第二次在第二层，依此类推
- 已选的分类显示勾选状态，再次点击取消勾选
- 至少保留一个分类被选中

### 2.2 渲染

- 使用 fl_chart 的 `BarChart` 配合多个 `BarChartRodData` 实现堆叠
- 每根柱子的各段按用户选择的顺序自底向上排列
- 颜色使用分类色，透明度 0.85
- 支持触摸 tooltip 显示分类名 + 时长

### 2.3 数据

- 按当前 range（日/周/月）计算每天的每分类时长
- 未选中的分类不参与堆叠，但总时长仍计入摘要卡片

## 3. 视觉修复

### 3.1 摘要卡片

- 参考原型文案：`今日 4h 20m +12%` / `本周 30h 30m +5%` / `日均 4h 21m -2%`
- 修复 change2/change3 为空的问题，所有卡片都显示变化百分比
- 正数绿色，负数红色

### 3.2 饼图

- 中心增加总计文案，如 `25h 总计`，大号数字 + 小字"总计"
- 选中分类时 tooltip 保留

### 3.3 整体视觉

- 卡片圆角 12px，阴影调优
- 字体大小/颜色向原型对齐
- 统一间距和留白
