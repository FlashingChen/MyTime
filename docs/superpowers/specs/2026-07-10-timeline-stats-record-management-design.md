# 时间线、统计与记录管理设计规格

**日期：** 2026-07-10  
**状态：** 已实施；本文保留设计细节，并在下方标注当前实现边界。

## 1. 目标与范围

本变更聚焦三个互相关联的体验：

- 修复时间线的日视图、可见时间范围和相邻记录重叠问题。
- 丰富统计页的信息层级，并使各统计范围使用正确的时间粒度。
- 在“我的”中提供全量记录管理，并补齐分类的安全编辑、删除流程。

时间线不再提供周视图，只保留日视图。该决定替代了原型、README 和旧规格中“日/周时间线”的描述。

不新增依赖。继续使用 Flutter、BLoC、Hive、fl_chart 与现有设计令牌。

## 2. 时间线

### 2.1 日视图与数据范围

- 移除日/周视图切换及周视图状态。
- 选择某日时，显示与该日 `[00:00, 次日 00:00)` 相交的记录；绘制前将记录裁剪到所选日期。
- 时间轴固定渲染 `00:00–24:00`，不再使用 `08:00–22:00` 的硬编码范围。
- 时间轴可纵向滚动，默认 60 px/小时。

记录必须满足结束时间晚于开始时间。跨午夜记录是受支持的：时间线和统计都按选中范围的相交片段计算。手动记录编辑器的开始与结束端点均可独立选择日期和时间，因此也可直接创建或编辑跨天记录。

### 2.2 双指缩放

- 不显示缩放按钮或缩放滑块。
- 在时间轴区域使用双指捏合缩放，范围为默认刻度的 `0.5×–2.0×`，即约 `30–120 px/小时`。
- 单指上下拖动保持原有滚动行为。
- 缩放过程中，以双指焦点对应的时间为锚点；更新内容高度和滚动偏移量后，该时间仍停留在原屏幕位置。
- 双击时间轴恢复 `1.0×`，并短暂显示“100%”反馈。
- 用底层指针监听计算双指距离，仅在两个及以上指针存在时更新缩放比例，避免缩放识别器与 `SingleChildScrollView` 的单指拖动竞争。

### 2.3 重叠排版

建立无 UI 依赖的日时间线布局计算器，输入记录、小时高度、最小卡片高度，输出每张卡片的顶部、高度、列号、列数。

1. 按开始时间、结束时间排序。
2. 将记录转换为视觉区间；结束位置为 `max(真实结束位置, 开始位置 + 最小卡片高度)`。
3. 按视觉区间划分连续冲突组，并在每组内采用最早空闲列分配。
4. 每组独立计算列宽；未与其他记录视觉冲突的卡片占满可用宽度。

这避免了短记录被最小高度放大后与相邻卡片相交，也不会让已结束冲突组影响后续卡片的宽度。

## 3. 统计页

### 3.1 统一统计区间

统计范围分别为本日、本周（周一开始）和本月。所有范围使用半开区间 `[start, end)`；计算记录时按记录与区间的相交部分累计，避免边界记录遗漏或重复。

摘要卡改为随选择范围更新：

| 范围 | 卡片一 | 卡片二 | 卡片三 |
| --- | --- | --- | --- |
| 本日 | 今日总时长 | 昨日总时长 | 较昨日变化 |
| 本周 | 本周总时长 | 日均 | 较上周变化 |
| 本月 | 本月总时长 | 日均 | 较上月变化 |

### 3.2 占比、趋势与建议

- 饼图中心显示当前范围总时长；图例按时长降序，显示时长、占比和记录数。点选分类时高亮该分区。
- 趋势图按范围选取粒度：本日按小时、本周按周一至周日、本月按日期。禁止把不同周的同一 weekday 聚合到一起。
- AI 建议的标题和文本使用当前范围名称，不再固定为“本周总结”。
- 保持既有深色、靛紫渐变和白色圆角卡片，不引入新的视觉体系。

## 4. 分类管理

所有分类（含首次启动的默认分类）支持新增、编辑和删除：

- 编辑名称或颜色后，所有按分类 ID 展示的历史记录、时间线和统计立即呈现新信息。
- 删除前显示确认对话框。
- 删除后会将关联记录的 `categoryId` 清空，使其显示为“未分类”。
- 至少保留一个分类；删除最后一个分类会被禁止。
- 不允许通过分类删除删除任何时间记录，也不会留下指向已删除分类的 `categoryId`。

## 5. 记录管理

在“我的”设置列表新增“记录管理”入口，进入独立页面。

- 读取全量记录并按开始时间倒序显示。
- 每一项显示分类名称、时间范围和可选备注；按日期分组和分类色展示是后续体验优化项。
- 页面提供新增入口；点击记录可编辑；删除需要二次确认。
- 新增和编辑复用同一记录编辑底部弹窗，字段为日期、开始时间、结束时间、分类和备注。
- 表单校验结束晚于开始并要求选择存在的分类；开始与结束端点各自提供日期和时间选择，并允许跨天范围。

数据层保留 `RecordRepository.update`，在 `RecordsBloc` 增加 `RecordUpdated` 事件并在成功后重新发布按开始时间倒序的记录列表。分类迁移由仓库协调：先批量迁移关联记录，成功后才删除分类；不在 UI 层逐条修改记录。记录和分类位于不同 Hive box，因此不承诺跨 box 原子事务，但该顺序不会产生失效的 `categoryId`。

## 6. 测试与验证

新增或扩展以下自动化测试：

- 时间线布局：全天边界、缩放位置、短时相邻记录、重叠组分列、后续记录恢复满宽。
- 时间线组件：双指缩放更新刻度，双击恢复默认刻度。
- 统计计算：日/周/月边界、跨范围相交累计、三种趋势粒度。
- 分类：默认和自定义分类均可编辑；删除后关联记录变为未分类；最后一个分类不能删除。
- 记录：新增、更新、删除、排序、表单时间校验。
