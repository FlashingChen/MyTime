# MyTime App Logo 设计规范

## 1. 设计目标

为 MyTime 设计一套可在 Android、iOS 及应用内全平台使用的 App Logo，延续现有简洁现代的视觉语言，强化「时间记录」品牌识别。

## 2. 设计原则

- **简洁现代**：无多余装饰，聚焦核心符号
- **品牌一致**：复用 App 现有配色与界面元素
- **全平台适配**：一次设计，覆盖启动图标、应用内 Logo、宣传物料
- **可扩展**：基于矢量，支持任意尺寸缩放

## 3. 方案概述

采用「渐变计时圆环 + MyTime 文字」方案。圆环与首页计时器视觉呼应，开口朝向右上方，营造时间流动感；底部品牌文字强化记忆。

## 4. 视觉规范

### 4.1 画布与外形

- 源文件尺寸：1024 × 1024 px
- 外形：圆角方形
- 圆角半径：22%（约 225 px），与 iOS 现代 App Icon 规范一致
- 背景色：纯白 `#FFFFFF`

### 4.2 核心图形：渐变计时圆环

- 圆环直径：约占画布宽度的 56%（约 574 px）
- 圆环线宽：36 px
- 颜色：线性渐变 `#6366F1`（左上）→ `#8B5CF6`（右下）
- 形态：开口圆环，开口角度约 45°，朝向右上方
- 端点样式：圆角端点
- 位置：画布垂直中轴，略偏上，为底部文字预留空间

### 4.3 品牌文字

- 内容：`MyTime`
- 位置：圆环正下方，与圆环中心垂直对齐
- 字体：现代无衬线，字重 600（SemiBold）
- 字号：约 96 px
- 颜色：主深色 `#1a1a2e`
- 字间距：-0.02em

### 4.4 安全区

- 图标主体（圆环 + 文字）位于画布中央 80% 安全区内
- 边缘预留足够空间，避免被各平台裁切或蒙版影响

## 5. 平台适配

| 平台/场景 | 输出规格 | 说明 |
|---|---|---|
| Android Adaptive Icon | 前景层（圆环+文字）+ 背景层（纯白） | 支持动态形状蒙版 |
| iOS App Icon | 1024×1024 圆角方形 | Apple 自动应用圆角 |
| 应用内/启动页 | 矢量 SVG | 可任意缩放，保持清晰 |
| 深色模式备选 | 背景 `#1a1a2e`，文字 `#FFFFFF` | 用于深色主题宣传图 |
| 小尺寸 favicon | 16×16 / 32×32 | 可简化为纯圆环，去掉文字 |

## 6. 色板

| 用途 | 色值 |
|---|---|
| 背景 | `#FFFFFF` |
| 主深色（文字） | `#1a1a2e` |
| 渐变起点 | `#6366F1` |
| 渐变终点 | `#8B5CF6` |

## 7. 输出文件清单

- `assets/logo/logo.svg` — 主矢量源文件
- `assets/logo/logo_dark.svg` — 深色模式版本
- `assets/logo/ic_launcher_foreground.svg` — Android 自适应图标前景
- `assets/logo/ic_launcher_background.svg` — Android 自适应图标背景
- `assets/logo/icon_mark.svg` — 无文字纯图形符号
- `ios/Runner/Assets.xcassets/AppIcon.appiconset/` 下各尺寸 PNG
- `android/app/src/main/res/mipmap-*/` 下各密度 PNG
- `web/icons/` 下 favicon 与 PWA 图标

## 8. 实现注意事项

- 所有图标文件使用 SVG 格式，符合项目「不使用 emoji，图标用 SVG 或自绘 CustomPainter」规范
- Android 自适应图标前景与背景需分离，前景禁止靠近边缘，避免被裁切
- iOS 图标无需预切圆角，Apple 会自动处理
- 生成 PNG 时使用无损导出，避免渐变出现色带

## 9. 验收标准

- [ ] 源文件 SVG 在 1024×1024 下清晰无锯齿
- [ ] Android 自适应图标在各密度下显示完整
- [ ] iOS 图标在 App Store 和桌面上比例协调
- [ ] 应用内 SVG Logo 在浅色/深色背景下均可识别
- [ ] 无文字纯图形符号版本在极小尺寸（16×16）下仍可辨认
