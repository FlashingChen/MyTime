# MyTime App Logo Implementation Plan

**Goal:** Replace the previous SVG-based logo with the user-provided PNG brand artwork, regenerate Android/iOS launcher icons, and update the in-app splash page accordingly.

**Architecture:** Store the master logo as a PNG in `assets/logo/`, use `flutter_launcher_icons` to generate platform-specific launcher icon PNGs, and display the same PNG inside the app via Flutter's `Image` widget.

**Tech Stack:** Flutter (Dart), PNG, `flutter_launcher_icons`

## Global Constraints

- Framework: Flutter (Dart)
- Brand logo provided as PNG raster artwork; app UI icons remain SVG or custom `CustomPainter`; no emoji
- Primary dark: `#1a1a2e`
- Accent gradient: `#6366F1` → `#8B5CF6`
- Do not introduce new runtime dependencies without justification; `flutter_launcher_icons` is a dev-only tool
- Follow the existing project structure under `lib/`, `android/`, `ios/`
- Source design spec: `docs/superpowers/specs/2026-07-09-app-logo-design.md`

---

## File Structure

| Path | Responsibility |
|---|---|
| `assets/logo/logo.png` | Master full-color logo raster (1024×1024) |
| `assets/logo/ic_launcher_foreground.png` | Android adaptive icon foreground (center graphic) |
| `assets/logo/ic_launcher_background.png` | Android adaptive icon background (`#1a1a2e`) |
| `assets/logo/icon_mark.png` | Standalone graphic mark without wordmark |
| `pubspec.yaml` | Asset declarations |
| `flutter_launcher_icons.yaml` | Generator configuration pointing to PNG sources |
| `lib/ui/pages/splash/splash_view.dart` | Splash/about page displaying the PNG logo |
| `test/ui/pages/splash/splash_page_test.dart` | Widget test for splash page |
| `android/app/src/main/AndroidManifest.xml` | Android app label set to `MyTime` |

## Task 1: Process and Store PNG Logo Assets

**Files:**
- Create/overwrite: `assets/logo/logo.png`
- Create/overwrite: `assets/logo/ic_launcher_foreground.png`
- Create/overwrite: `assets/logo/ic_launcher_background.png`
- Create/overwrite: `assets/logo/icon_mark.png`
- Delete old SVG assets: `assets/logo/*.svg`

**Steps:**

1. Take the user-provided raster logo and scale/crop it to 1024×1024, preserving the rounded corners.
2. Save the full rounded icon as `assets/logo/logo.png`.
3. Create `assets/logo/ic_launcher_foreground.png` by masking the center circular area (graphic only, no text) for Android adaptive icons.
4. Create `assets/logo/ic_launcher_background.png` as a solid `#1a1a2e` square.
5. Create `assets/logo/icon_mark.png` as the standalone center graphic.
6. Remove obsolete `assets/logo/*.svg` files.
7. Commit.

## Task 2: Update Configuration

**Files:**
- Modify: `pubspec.yaml`
