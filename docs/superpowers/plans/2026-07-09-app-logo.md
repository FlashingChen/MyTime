# MyTime App Logo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a platform-ready MyTime app logo based on the approved design spec, generate Android/iOS launcher icons, and integrate the logo into the Flutter app.

**Architecture:** Store the logo as SVG source files in `assets/logo/`, use `flutter_launcher_icons` to generate platform-specific PNGs from a master source, and expose the SVG logo inside the app via `flutter_svg` for in-app branding.

**Tech Stack:** Flutter, SVG, `flutter_svg`, `flutter_launcher_icons`

## Global Constraints

- Framework: Flutter (Dart)
- Icons must be SVG or custom `CustomPainter`; no emoji
- Primary dark: `#1a1a2e`
- Accent gradient: `#6366F1` → `#8B5CF6`
- Background light: `#F8F9FA`, card white: `#FFFFFF`
- Do not introduce new runtime dependencies without justification; `flutter_launcher_icons` is a dev-only tool for icon generation
- Follow the existing project structure under `lib/`, `android/`, `ios/`
- Source design spec: `docs/superpowers/specs/2026-07-09-app-logo-design.md`

## Task 2: Configure Flutter Assets and Launcher Icon Generator

**Files:**

- Create: `flutter_launcher_icons.yaml`

**Interfaces:**
- Consumes: SVG source files from Task 1

- [ ] **Step 1: Add asset declarations to `pubspec.yaml`**

Modify the `flutter:` section of `pubspec.yaml`:

```yaml

  uses-material-design: true
  assets:
    - assets/logo/logo.svg
    - assets/logo/logo_dark.svg
    - assets/logo/icon_mark.svg
```

- [ ] **Step 2: Add `flutter_launcher_icons` dev dependency**

Modify the `dev_dependencies:` section of `pubspec.yaml`:

```yaml
dev_dependencies:
  flutter_test:
    sdk: flutter
  flutter_lints: ^5.0.0
  bloc_test: ^9.1.7
  hive_ce_generator: ^1.8.1
  build_runner: ^2.4.13
  flutter_launcher_icons: ^0.14.1
```

- [ ] **Step 3: Create `flutter_launcher_icons.yaml`**

Create `flutter_launcher_icons.yaml` at the project root. The generator requires PNG inputs, so the config points to generated PNG intermediates rather than the SVG sources.

```yaml
# PNG intermediates used because flutter_launcher_icons does not accept SVG input directly.
# These PNGs are generated from the SVG sources in assets/logo/ and must be regenerated
# if the SVGs change.
flutter_launcher_icons:
  android: true
  ios: true
  image_path: "assets/logo/logo.png"
  adaptive_icon_background: "assets/logo/ic_launcher_background.png"
  adaptive_icon_foreground: "assets/logo/ic_launcher_foreground.png"
  min_sdk_android: 21
  remove_alpha_ios: true
```

- [ ] **Step 4: Generate PNG intermediates from SVG sources**

Install `rsvg-convert` (macOS: `brew install librsvg`; Linux: `apt-get install librsvg2-bin`), then generate the PNGs required by `flutter_launcher_icons`:

```bash
rsvg-convert -w 1024 -h 1024 assets/logo/logo.svg -o assets/logo/logo.png
rsvg-convert -w 1024 -h 1024 assets/logo/ic_launcher_foreground.svg -o assets/logo/ic_launcher_foreground.png
rsvg-convert -w 1024 -h 1024 assets/logo/ic_launcher_background.svg -o assets/logo/ic_launcher_background.png
```

Expected: `assets/logo/logo.png`, `assets/logo/ic_launcher_foreground.png`, and `assets/logo/ic_launcher_background.png` are created at 1024×1024.

- [ ] **Step 5: Install dependencies**

```bash
flutter pub get
```

Expected: Dependencies resolve without errors.

- [ ] **Step 1: Create the splash page**

Create `lib/ui/pages/splash/splash_page.dart`:

```dart
import 'package:flutter/material.dart';
import 'package:flutter_svg/flutter_svg.dart';

/// A simple splash/about page displaying the MyTime logo.
class SplashPage extends StatelessWidget {
  /// Creates a [SplashPage].
  const SplashPage({super.key});

  @override
  Widget build(BuildContext context) {
    final isDark = Theme.of(context).brightness == Brightness.dark;
    final assetName = isDark
        ? 'assets/logo/logo_dark.svg'
        : 'assets/logo/logo.svg';

    return Scaffold(
      backgroundColor: isDark ? const Color(0xFF1a1a2e) : const Color(0xFFF8F9FA),
      body: Center(
        child: Padding(
          padding: const EdgeInsets.all(48),
          child: SvgPicture.asset(
            assetName,
            width: 192,
            height: 192,
          ),
        ),
      ),
    );
  }
}
```

```dart
import 'package:flutter/material.dart';
import 'package:flutter_svg/flutter_svg.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:mytime/ui/pages/splash/splash_page.dart';

void main() {
  group('SplashPage', () {
    testWidgets('renders SvgPicture in light mode', (tester) async {
      await tester.pumpWidget(
        const MaterialApp(home: SplashPage()),
      );

      expect(find.byType(SvgPicture), findsOneWidget);
    });

    testWidgets('uses dark logo in dark mode', (tester) async {
      await tester.pumpWidget(
        MaterialApp(
          theme: ThemeData.dark(),
          home: const SplashPage(),
        ),
      );

      final svgPicture = tester.widget<SvgPicture>(find.byType(SvgPicture));
      final assetName = svgPicture.pictureProvider.toString();
      expect(assetName, contains('logo_dark.svg'));
    });
  });
}
```
